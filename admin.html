Instructions pour modifier les données de manière permanente

Pour que les modifications soient visibles par tous les visiteurs du site :

  1. Exportez les données au format JSON via le bouton ci-dessus
  2. Ouvrez le fichier data.js dans un éditeur de texte
  3. Remplacez le contenu des tableaux alumniData et stagesData
  4. Enregistrez le fichier et poussez les modifications sur GitHub

Le site étant hébergé sur GitHub Pages (statique), il n'y a pas de base de données côté serveur.
